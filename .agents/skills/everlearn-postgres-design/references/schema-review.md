# PostgreSQL Schema Review

## 模型

- 表归属单一领域模块；ownerId 和生命周期明确。
- 主键、外键、唯一性、可空性、删除与恢复语义明确。
- 状态值受约束；稳定业务不变量进入数据库。

## 查询与索引

- 为每个索引列出实际查询、过滤、排序和游标。
- 复合索引列顺序与查询一致，避免重复和未使用索引。
- 树移动、恢复和并发写入具有事务与锁策略。

## 迁移

- 迁移兼容已有数据，不假设空库。
- 大表变更评估锁、回填、默认值和发布顺序。
- 本地 rollback 可执行；不可逆变更说明恢复方案。
- 迁移后重新生成 Kysely 数据库类型。
- 多语句迁移包在单个事务，失败不留半建结构。

## 验证

- 使用真实 PostgreSQL 验证约束、级联、事务和幂等。
- 检查 ownerId 过滤、参数化 SQL 和敏感数据边界。
- 代表性查询有 EXPLAIN 或明确的索引推理证据。
