# UI 交付检查表

## 规格

- 页面目的、主任务、主操作和离开路径明确。
- 桌面与移动布局明确；移动端不加载被排除的创作能力。
- 数据来源和异步状态与页面规格一致。

## 复用

- 已搜索 packages/ui 和当前组件库目录。
- 标准控件直接复用；自研缺口有理由和所有权。
- 同类图标来自同一图标库；菜单项和导航项支持图标及可访问名称。
- 共享组件不是只转发属性的包装。

## 状态

- 正常、加载、空、失败、部分成功、无权限和离线按适用范围覆盖。
- 空态是结构化区块（视觉锚点 + 缺失对象说明 + 唯一主行动），不是一行灰字；同实体空态文案跨页一致。
- 内容性失败（404、参数校验）不显示重试按钮；网络/服务器失败提供就地重试。
- 全局入口（顶栏、导航）没有真实数据源的计数、徽标、链接一律不渲染。
- 长标题、长列表、窄宽度、键盘导航和焦点恢复可用。
- 错误信息说明对象、原因类别与下一步；破坏性确认文案只承诺已上线的恢复能力。

## 视觉与动效

- 只使用语义 Token，不写主题色值；`pnpm check:design-tokens` 通过（无未定义 var() 引用、断点只有 48em/80em）。
- Mantine 语义色走 design-system.md 映射表；无 `color="red"` 或裸色值。
- CSS Modules 一律 `styles['kebab-name']` 访问；无 camelCase 访问 kebab 类名。
- 阅读区安静；卡片、阴影与强调色有信息职责。
- 主动画唯一；reduced motion 下取消位移、缩放和路径运动（含 Mantine 浮层，globals.css 兜底块已覆盖）。
- 浏览器实页完成桌面与移动走查，并附浅色、深色、390px 移动端三张截图进任务证据；无截图不得声明完成。

## 精致度

- 间距、圆角、阴影、颜色、字号只引用语义 Token，无写死值；同控件跨页面一致。
- 每个可交互元素覆盖 hover、active、focus-visible、disabled、loading、error；禁用态与可用态视觉差明确。
- 浮层关闭后焦点回触发器、打开时进入浮层；主流程可仅用键盘完成。
- 文案一致、可行动；错误说明对象、原因类别与下一步；空态说明缺失对象并给出主行动。
- 每页只有一个主操作；Skeleton 保持最终布局尺寸；失败区域就地重试。
- 正文、控件、焦点满足 WCAG 2.1 AA；浅色/深色与 reduced motion 下关键页面各走查一次。
