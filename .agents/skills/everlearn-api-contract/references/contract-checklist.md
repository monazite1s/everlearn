# API 契约检查表

## 请求

- 资源、方法、路径、身份、权限和所有权过滤明确。
- DTO 校验区分缺失、格式错误、领域冲突和无权限。
- 写操作定义版本号或幂等键；列表定义游标、过滤和排序。

## 响应

- 成功状态码与响应投影明确，不直接序列化数据库行。
- 错误使用 code、message、requestId、details?。
- 时间、ID、枚举和可空字段与公共契约一致。

## 异步

- 先落库运行记录，再投递队列。
- SSE 包含 eventId、type、runId、sequence、timestamp、payload。
- 断线恢复、轮询降级、取消、重试和部分完成行为明确。

## 前端

- 客户端与类型由服务端契约生成或派生。
- 页面覆盖加载、空、冲突、失败和重试。
- Mock 仅存在于测试、Story 或显式开发夹具。
