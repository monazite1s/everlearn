# Everlearn 产品规格

## 目标

Everlearn 是面向个人学习者的知识工作台。它将个人知识库、可信资讯简报、系统教程生成和可观察的 Agent/Workflow 放在同一产品内，使资料最终沉淀为可编辑、可检索、可引用的知识库文档。

产品成功不以文档数或模型调用量衡量，而以四个闭环衡量：用户能记录与组织知识；能找到并验证既有内容；能自动获得有来源的资讯；能把主题研究转化为可持续维护的系统教程。

## 用户与语言

- 目标用户是使用桌面浏览器进行长期学习和资料整理的个人开发者或知识工作者。
- 首期使用固定本地用户，不提供注册、登录或权限配置界面。
- 所有业务对象从首个迁移开始保存 `ownerId`，不得使用全局单例数据模型。
- 产品界面、错误提示、系统 Prompt 和默认生成结果使用简体中文；检索可读取其他语言来源。

## 产品结构

一级导航固定为：首页、知识库、资讯、教程、工作流、设置。各模块导航同级，但知识库是首页重点和所有成品的统一内容载体；AI 与 Agent 是跨模块能力，不设置独立“AI 创作中心”。

### 知识库

- 一个用户可拥有多个知识库，知识库不可嵌套。
- 知识库内部只有文档节点；文档有正文，也可拥有无限层级子文档。
- 知识库分组是后续整理能力，仅一层且不保存内容，首期不实现数据模型或 UI。
- 支持 Inbox 快速记录、标签、全局搜索、内部文档链接、反向链接、修订和回收站。
- 删除知识库或文档子树进入回收站 30 天。恢复时优先回到原位置，父节点不存在则恢复到知识库根部。

### AI 编辑与问答

- 新文档可由 AI 自动创建；修改已有文档必须先展示差异并由用户接受。
- 取消或拒绝不得改变正文；接受写入创建关联生成记录和文档修订。
- 问答范围必须明确为当前文档或当前知识库，回答必须引用文档与块；证据不足时明确说明未找到。
- 模型不可用不影响阅读、手工编辑、普通搜索和既有文档。

### 资讯

- 订阅由自然语言主题、RSS/Atom 或站点来源、包含关键词和排除关键词组成。
- 支持按用户时区每日、每周自动运行和手动立即运行，不开放 Cron 与事件触发。
- 所有简报写入系统维护的“资讯知识库”，按订阅主题和日期组织。
- 成功运行直接发布正式文档。质量不足也发布，但文档顶部必须展示来源不足、缺失引用或失败步骤等结构化警告。
- 系统只保存来源元数据、链接、摘要、必要短摘录与内容指纹，不保存可完整阅读的外部正文。

### 系统教程

- 默认结合用户指定知识库和 Web 研究资料生成教程。
- 第一次人工确认锁定研究目标、受众、深度和来源范围；研究完成后第二次确认可编辑大纲。
- 确认大纲后立即创建独立知识库和章节占位文档，章节独立生成并逐步可读。
- 单章失败不阻塞其他章节，可从失败步骤单独重试；所有事实性结论必须关联实际取得的来源。

### Agent 与 Workflow

- 提供内置资讯简报、教程生成模板和从零创建能力。
- 步骤列表与 React Flow 画布编辑同一份 Workflow 定义；列表视图是完整且可访问的编辑入口。
- Workflow 采用草稿、校验、发布制；已发布版本不可变，运行绑定具体版本。
- 只允许知识库、检索、搜索、LLM、资讯处理等内置工具及受控 Provider Adapter。
- 不提供任意 HTTP、脚本或代码执行节点。

## 设备与内容边界

- 桌面端是唯一完整创作环境。
- 移动端仅支持阅读、目录浏览、普通搜索、引用跳转和任务状态查看；编辑入口明确提示使用桌面端。
- 编辑器附件支持图片展示和普通文件下载，不解析 PDF、Office 或音视频内容，也不参与 AI 检索。
- 首期导入导出为单个 Markdown、包含附件的 ZIP 导入，以及知识库或文档子树的 Markdown ZIP 导出。

## 后置账号、分享与克隆

- 多账号、公开分享与克隆在核心模块完成后实施。
- 所有共享内容只读，不存在协作者编辑、评论、实时协作、文档锁或冲突合并。
- 可分享整个知识库或任意文档子树；分享链接默认 `noindex`，可撤销并可设置过期时间。
- 登录用户可克隆共享内容。克隆是内容和可访问附件的独立深拷贝，记录来源与克隆时间，之后不与原内容同步。

## 明确排除

- Yjs、CRDT、实时协作、离线优先和移动端创作。
- Notion Database、表格视图、看板、知识图谱和高级分栏。
- 登录态抓取、绕过网站限制、任意 HTTP、任意代码执行和外部自动发布。
- 全局通知中心、邮件通知、事件触发自动化和首期 Cron 编辑器。
- Notion/语雀专用迁移、多格式附件知识摄取和外部网页全文归档。

## 产品级验收

1. 固定本地用户能完成知识库创建、嵌套文档编辑、自动保存、修订恢复、搜索和 Markdown 导出。
2. AI 对已有内容的修改只有接受后生效；知识库问答返回可跳转的块级引用。
3. 定时资讯无需重复输入 Prompt，能自动生成直接发布且来源可追溯的日报或周报。
4. 教程经过两次确认后立即建库，章节可并行完成且失败章节可独立恢复。
5. 用户能查看、复制、创建、发布和运行受限 Workflow，并观察每个节点的状态和输出摘要。
