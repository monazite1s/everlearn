# 布局与导航

## 一级导航与路由

| 入口   | 路由         | 职责                                   |
| ------ | ------------ | -------------------------------------- |
| 首页   | `/`          | 知识库优先的工作入口和跨模块状态摘要。 |
| 知识库 | `/knowledge` | 知识库列表、Inbox、搜索和回收站入口。  |
| 资讯   | `/news`      | 订阅、计划、简报和运行状态。           |
| 教程   | `/tutorials` | 教程任务创建、确认和进度。             |
| 工作流 | `/workflows` | 模板、定义、版本、计划和运行。         |
| 设置   | `/settings`  | 外观、Provider、时区、存储和诊断。     |

通用 AI 不占一级导航。全局搜索通过顶部搜索框或快捷键打开 `/search` 结果层；Inbox 路由为 `/knowledge/inbox`。

## 桌面应用壳

```text
┌ 顶栏 48：位置 / 全局搜索 / 新建 / 运行状态 ┐
├ 左栏 264 ┬ 中央 min 640                     ┬ 右栏 320 ┤
│ 一级导航 │ 当前页面主要内容                 │ 上下文   │
│ 页面树   │ 唯一主行动                       │ 引用/AI  │
└──────────┴──────────────────────────────────┴──────────┘
```

- 最大内容宽度由页面决定；编辑正文为 760px，列表和 Workflow 可使用全部中央宽度。
- 左栏按页面显示文档树、订阅、教程或 Workflow 列表；不存在跨模块混合树。
- 右栏只显示当前对象上下文，可折叠；同一页面不得再叠加第二个固定侧栏。
- 顶栏的运行状态只显示进行中数量并链接到当前模块，不构成全局通知中心。

## 响应式规则

- `> 1280px`：三栏可用，左右栏可独立折叠。
- `769–1280px`：默认收起右栏，左栏保持；上下文由按钮打开覆盖面板。
- `≤ 768px`：只读模式。左栏改为抽屉；隐藏编辑、导入、配置和画布操作；正文、搜索与状态页面保持可访问。
- 移动端触发创作路由时显示说明和“返回阅读”操作，不渲染残缺编辑器。

### 实现约定

- 应用壳基于 shadcn Sidebar 官方骨架（ADR 001/002）：`SidebarProvider` + `Sidebar variant="inset" collapsible="icon"` + `SidebarInset`；文件按官方 dashboard-01 粒度拆分（app-sidebar / nav-main / appearance-menu / site-header / page-breadcrumb）；左栏宽 16rem、折叠 48px 图标列；`Cmd/Ctrl+B`、顶栏 SidebarTrigger 与 SidebarRail 均可折叠，状态持久化（localStorage）。品牌行采用官方 SidebarMenuButton size="lg" + tooltip 形态。
- 外观控制（浅色/深色/跟随系统）是侧栏底部（SidebarFooter）的官方 mode-toggle 下拉；顶栏不承载「新建」等创作入口（创作入口在具体页面内）。
- 断点只有两档：`md`（48rem/768px）与 `xl`（80rem/1280px），在主题入口 CSS 以 `--breakpoint-*` 定义；禁止第三种断点写法。移动端（< 768px）左栏复用 Sidebar 内置 Sheet 行为，不另写抽屉。
- 顶栏高度以 `--header-height` token 记录；视口高度计算用 `dvh`。
- 右侧上下文栏在编辑器上线前不渲染（ADR 002 决策：静态占位面板撤下，待真实对象上下文能力就绪后以 `aside`/Sheet 形态回归）；当前页面宽度全部由中央内容区使用。
- 顶栏入口在对应能力上线前不渲染：全局搜索待 Command Menu，运行状态待运行系统数据源。禁止挂接假计数或死链接。
- 页面容器、页头（标题/说明/操作区）统一使用 `apps/web/src/app/page-shell.tsx`，不得在 feature 内重写容器样式；模块定位由顶栏 Breadcrumb 表达，页头不再渲染眉题等伪面包屑。

## 导航行为

- 当前一级入口、知识库和文档同时以文本、`aria-current` 和知识脊线标识。
- 文档编辑页离开前先提交未完成的防抖保存；失败时保留本地内容并阻止无提示离开。
- 浏览历史记录真实路由，不用仅靠客户端状态伪造页面切换。
- Command Menu 支持打开最近文档、全局搜索和新建文档，不承载危险操作。
- 面包屑显示当前文档祖先；深层级折叠中间项，不截断当前标题。

## 页面切换与焦点

- 路由切换后焦点移到页面标题；Dialog 关闭后回到触发器。
- 左栏折叠状态按设备保存；右栏是否打开按页面会话保存，不跨对象强制复用。
- Skeleton 保持最终布局尺寸；不使用全屏 Spinner 掩盖可继续使用的导航。
- 网络离线时保留已加载阅读内容；写操作禁用并明确说明尚未保存，不承诺离线编辑。
