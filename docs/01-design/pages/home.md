# 页面规格：首页

## 目的与路由

- 路由：`/`。
- 目的：让用户继续最近学习、进入知识库或快速记录；其他模块只提供状态和快捷入口。
- 入口：登录后的默认页、一级导航“首页”。离开：知识库、文档、Inbox、资讯运行、教程任务或 Workflow 运行。

## 布局

- 中央上方显示“继续学习”：最近打开的 6 篇文档，包含知识库、路径和更新时间。
- 中央主体显示知识库列表，默认按最近活动排序，提供新建知识库主操作。
- 快速记录为单行输入加展开编辑区，提交后进入 Inbox；不得要求先选知识库。
- 右栏显示进行中的资讯、教程和 Workflow，最多各 3 项；无任务时不显示空卡片。
- 移动端只显示最近文档、知识库列表和运行状态，隐藏快速记录输入。

## 数据与操作

- 数据：`KnowledgeBaseSummary`、`RecentDocument`、`InboxCapture`、`ActiveRunSummary`。
- 新建知识库需要名称；成功后进入知识库首页，失败保留输入。
- 快速记录支持纯文本或单个 URL；成功清空输入并提供“打开 Inbox”。
- 点击运行摘要进入对应模块运行详情，不在首页展开日志。

## 状态

| 状态 | 行为 |
|---|---|
| 首次使用 | 解释知识库用途，主操作为“创建第一个知识库”，仍保留快速记录。 |
| 加载 | 最近文档与知识库分别显示稳定尺寸 Skeleton。 |
| 部分失败 | 成功区域继续可用，失败区域显示重试。 |
| 离线 | 展示缓存阅读入口；新建与快速记录禁用。 |
| 无权限 | 首期不会出现；后续账号异常跳转登录，不泄露数据摘要。 |

## 可访问性与动效

- 页面标题为唯一 `h1`；各区域使用 `h2`。
- 知识库列表支持键盘进入，不把整张卡片嵌套多个链接。
- 最近文档切换仅使用 180ms 透明度；reduced motion 下立即更新。

## E2E 验收

1. 新用户可从空状态创建知识库并自动进入该知识库。
2. 快速记录成功进入 Inbox，失败时文本不丢失。
3. 最近文档和进行中任务可跳转到正确对象。
4. 任一摘要接口失败不阻止其他区域操作。
