# 页面规格：教程

## 目的与路由

- `/tutorials`：教程书架列表与创建入口。
- `/tutorials/:tutorialId`：教程详情；URL 保存 `?view=tree|list|graph`（缺省 `tree`），刷新可恢复同一视图，非法值 replace 回默认。
- `/tutorials/:tutorialId/compose`：Agent 对话创作子路由，取代旧独立向导页；确认闸门与全部创作交互收敛在对话内。
- 章节阅读进入标准文档路由 `/knowledge/:knowledgeBaseId/documents/:documentId`，复用现有编辑器渲染；移动端使用只读渲染器。
- 入口：一级导航、首页运行摘要、知识库列表的教程徽标、章节文档面包屑。离开：章节文档、来源原文、其他一级模块。
- 教程产出库是普通知识库加 `kind=tutorial` 徽标（下称教程徽标）：知识库列表照常显示、不隐藏、不单独分区；`/tutorials` 只列教程知识库，不混入普通知识库。

## 教程列表（书架）

- 书架卡片：标题、进度 x/y 章、状态徽章（状态语言：生成中、部分完成、已完成、失败、已取消）、继续阅读定位（上次阅读章节，无记录则第一章）。
- 质量对齐知识库入口：名称、进度、元信息以字重、字号、颜色三通道区分，具备 hover 边框反馈；状态不只依赖颜色。
- 主操作「新建教程」打开最小创建弹窗：主题必填，受众、目标、深度可选；提交创建 `draft_scope` 的 Tutorial 并跳转 `/tutorials/:id/compose`，范围细化在对话中完成。
- 空态为结构化区块：视觉锚点、缺失对象说明与唯一主行动「新建教程」。

## 详情页三视图

- 左栏为章节树，知识脊线标记当前章节位置；主区为 Tabs「树｜列表｜图」，是同一份章节数据与 `dependsOn` 的三种投影，切换只 replace `?view=`。
- 树视图（默认）：大纲层级展开，节点显示章节标题、状态徽章与知识脊线。
- 列表视图：平铺全部章节，含标题、状态、依赖标签与进度；是图视图的无障碍等价入口，可独立完成全部信息读取。
- 图视图：dagre 自动布局加 SVG 自绘节点与边，不引入 React Flow；只渲染本教程大纲内已确认的前置与依赖边，不跨教程、不自动扩展；节点点击进入该章节文档页。
- 图节点超过 50 个时默认只展开当前章节 2 跳邻域，其余子图折叠为「+N」聚合节点，点击聚合节点展开；展开状态不写入 URL。
- 单章失败保留占位与失败原因，不阻塞无依赖章节；失败章节提供单章重试，重试沿用幂等键并写入新修订。

## compose 对话创作

- 布局：左 1/3 对话流（消息列表与输入框），右 2/3 教程实时预览（随会话状态显示研究计划、大纲或章节生成进度）。
- 两个副作用确认闸门以对话内「确认卡」呈现：
  - 开始研究：确认后固化不可变研究范围并发起研究运行；确认前不调用任何研究工具。
  - 确认大纲并建库：确认后原子创建教程知识库与章节占位文档；确认前不创建任何知识库或文档。
  - 确认卡说明将执行的动作、目标、影响与不可逆点；接受调用既有确认端点（幂等），拒绝不改变任何已落库内容。
- Agent 提议（范围调整、大纲修订、章节选题）只以提案消息呈现：接受才落库（生成新大纲版本或授权章节生成），拒绝不产生变更；提案状态持久化，重复决议返回首次结果。
- 全新占位章节的首次填充视为已由大纲确认授权，直接生成；用户编辑过的章节（最近修订来源为 manual）Agent 改写前必须展示差异并经接受，复用 Generations 差异接受契约。
- researching/generating 阶段显示阶段名与真实计数（如「章节生成中 3/12」「已获取来源 8」），不伪造百分比。
- 消息、提案与确认卡按教程持久化；刷新或重进恢复完整上下文；Agent 回复经运行 SSE 流式呈现。

## 数据与接口

- 数据实体：`Tutorial`、`ResearchScope`、`TutorialOutline`、`TutorialChapter`、`TutorialMessage`、`WorkflowRun`、目标 `KnowledgeBase`（kind=tutorial）与章节 `Document`。
- `GET /tutorials`：书架列表，返回标题、进度 x/y、状态与最近活动；`POST /api/v1/tutorials` 以最小字段创建草案。
- `GET /api/v1/tutorials/:id/compose`：会话快照，含分页消息、待处理提案与确认卡、当前大纲与章节状态。
- `POST /api/v1/tutorials/:id/compose/messages`：以幂等键同步发送用户消息，返回 200 与含 Agent 回复的消息列表；研究与章节运行的流式更新仍经既有 `/workflow-runs/:id/events`。
- `POST /api/v1/tutorials/:id/compose/proposals/:proposalId/accept|reject`：决议提案；重复决议返回首次结果。
- 确认闸门沿用 `/:id/confirm-scope` 与 `/:id/confirm-outline`；单章重试沿用 `/tutorial-chapters/:id/retry`；章节差异接受沿用 `/generations/:id/accept`。
- 大纲确认后不可原地篡改，只能创建新版本；章节完成与重试都写入文档修订。

## 异步行为

- 研究与章节生成先建运行记录再入队；compose 页面订阅运行 SSE，断线用 `Last-Event-ID` 重连，事件窗口失效收到 `stream.reset` 后重新拉取会话快照。
- 章节按依赖调度，无依赖章节并行；完成即可读，单章失败可单独重试，整体可处于部分完成。
- 用户离开页面不中断运行；返回时从会话快照恢复进度，不重复发送消息。

## 状态与反馈

| 状态         | 行为                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| 空列表       | 结构化空态加唯一主行动「新建教程」。                                       |
| 加载         | 书架与详情显示保持最终布局尺寸的 Skeleton，不使用全屏 Spinner。            |
| 草稿未确认   | 详情页与 compose 均可进入；确认卡是唯一触发研究与建库的入口。              |
| 研究中       | 对话流展示阶段与来源计数，可取消；预览区显示已确认范围。                   |
| 等待大纲确认 | 大纲可经提案修订；未建库前知识库列表不出现该教程。                         |
| 生成中       | 三视图与预览显示真实计数；完成章节立即可读。                               |
| 部分完成     | 明确标记失败或警告章节，提供单章重试。                                     |
| 来源不足     | 在大纲或章节标记覆盖缺口，不把模型常识当作研究证据。                       |
| 发送失败     | 消息保留在输入区或标记失败状态，提供重试，不静默丢弃。                     |
| 离线         | 已生成章节与历史消息可读；发送、确认、重试与数据请求禁用。                 |
| 无权限       | 教程不存在或不属于当前用户时统一不可访问状态，不泄露标题，404 不提供重试。 |

## 移动端

- 书架与详情三视图可阅读，`?view=` 生效；章节节点点击进入只读渲染器。
- compose 属创作路由：显示说明与「返回阅读」，不渲染对话输入与确认卡操作。
- 新建、确认、提案决议、重试与差异接受在移动端隐藏；运行状态与章节进度保持可读。

## 可访问性与动效

- 图视图不是唯一通道：列表视图承载全部章节与依赖信息；图内节点可 Tab 聚焦、Enter 打开，依赖关系在可访问名称中以「依赖 X」文字描述，边不作唯一载体。
- 视图 Tabs 支持方向键；知识脊线除视觉外以 `aria-current` 标识当前章节。
- 动效：视图切换与图布局变化 220–320ms；章节状态即时更新，不使用循环动效与虚假百分比；reduced motion 下取消布局位移动画，立即呈现最终布局。
- 阶段计数以文本更新并经 `aria-live` 宣告阶段变化，不逐字播报流式输出。

## E2E 验收

1. 两次确认卡接受前无研究调用、无知识库与文档创建；接受后立即出现教程知识库与章节占位。
2. 提案拒绝不落库、接受才落库；刷新后消息、提案与确认卡状态一致；重复决议返回首次结果。
3. 用户编辑过的章节改写先展示差异并经接受；全新占位章节首次填充直接完成。
4. 树、列表、图三视图渲染同一章节数据；`?view=` 刷新恢复；默认视图为树。
5. 图视图只含本教程已确认依赖；50+ 节点折叠为「+N」并可展开；仅用列表视图可完成全部信息读取。
6. 章节节点与继续阅读进入正确文档路由；单章重试只更新目标章节并创建新修订。
7. 知识库列表显示教程知识库与教程徽标，不隐藏；教程列表不混入普通知识库。
8. 键盘与 axe Critical/Serious 零问题；浅色、深色、390px 与 reduced motion 走查通过。
