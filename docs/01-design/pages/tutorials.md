# 页面规格：教程

## 目的与路由

- `/tutorials`：教程任务列表和最近生成的教程知识库。
- `/tutorials/new`：研究范围配置与第一次确认。
- `/tutorials/:tutorialId`：研究、大纲确认、章节进度和失败恢复。
- 成品章节使用标准知识库文档路由阅读和编辑。
- 入口：一级导航、首页运行摘要和教程知识库关联入口。离开：章节文档、来源或其他一级模块。

## 数据与接口

- 数据：`Tutorial`、`ResearchScope`、`TutorialOutline`、`TutorialChapter`、`WorkflowRun`、目标 `KnowledgeBase`。
- 使用教程草案、两次确认、运行 SSE、章节重试和取消接口；确认端点均要求幂等键。
- 章节首次完成和重试都写入文档修订；大纲确认后不可原地篡改，只能创建新版本或新教程。
- 首期固定本地用户可创建；移动端和后续公开页面只读。

## 创建与两次确认

1. 用户输入主题、目标读者、现有水平、学习目标、深度、希望覆盖/排除内容、可用知识库和 Web 来源范围。
2. 页面展示规范化研究计划和预计范围；用户确认后才开始研究。
3. 研究完成后展示可编辑大纲：前置知识、章节依赖、目标、概念、示例/练习和证据覆盖。
4. 用户确认大纲后立即创建独立知识库、文档树和章节占位；之后章节自动生成，不逐章打断。

第一次确认前不调用研究工具；第二次确认前不创建教程知识库。修改已确认的研究范围要创建新研究运行，不能篡改原快照。

## 进度与章节

- 左栏显示章节树及待运行、运行中、完成、质量警告、失败状态。
- 中央显示研究结果、大纲或当前章节；右栏显示来源覆盖和当前运行步骤。
- 完成章节立即可读；失败章节保留占位和失败原因，不阻塞无依赖章节。
- 重试单章使用原大纲、最新允许来源和新的运行尝试；成功后写入新修订。
- 教程整体状态允许“部分完成”，直到所有必需章节完成或用户取消剩余章节。

## 状态

| 状态         | 行为                                                   |
| ------------ | ------------------------------------------------------ |
| 等待研究确认 | 可编辑范围；无后台运行。                               |
| 研究中       | 展示查询、来源数量和阶段，可取消。                     |
| 等待大纲确认 | 大纲可编辑、重排和重新研究；尚未建库。                 |
| 生成中       | 知识库已存在，章节逐步开放阅读。                       |
| 部分完成     | 明确失败或警告章节，并提供单章重试。                   |
| 来源不足     | 在大纲或章节上标记覆盖缺口，不把模型常识当作研究证据。 |
| 离线         | 已生成章节可读；确认、编辑和重试禁用。                 |

## 移动端、可访问性与动效

- 移动端可阅读教程任务状态和已生成章节，不可创建、确认、编辑大纲或重试。
- 大纲重排必须提供键盘上移/下移替代操作。
- 阶段动画表现“研究 → 大纲 → 建库 → 章节”，不展示无法计算的虚假百分比；reduced motion 下使用静态步骤列表。

## E2E 验收

1. 第一次确认前无研究调用，第二次确认前无知识库或章节文档。
2. 确认大纲后立即出现结构一致的独立知识库和占位文档。
3. 完成章节可先行阅读，单章失败不阻塞其他章节。
4. 单章重试只更新目标章节并创建新修订。
5. 所有事实引用来自实际取得的来源或用户知识库块。
