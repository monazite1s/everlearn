# 页面规格：资讯

## 目的与路由

- `/news`：订阅与最近简报。
- `/news/subscriptions/new`、`/news/subscriptions/:subscriptionId`：创建或编辑订阅。
- `/news/runs/:runId`：一次执行的来源、步骤和错误详情。
- 成品文档在系统“资讯知识库”中阅读和编辑。
- 入口：一级导航、首页运行摘要和资讯知识库简报链接。离开：简报文档、设置 Provider 或其他一级模块。

## 数据与接口

- 数据：`NewsSubscription`、`NewsSource`、`DigestRun`、`DigestItem`、`WorkflowRun`、输出 `Document`。
- 使用订阅、Schedule、Digest Run、步骤重试和运行 SSE 接口；表单不直接提交 Cron。
- 首次发布创建自动化修订；重试成功更新同一文档并创建新修订，历史运行不被覆盖。
- 首期固定本地用户可配置；移动端和 M7 分享访问只读。

## 列表与订阅配置

- 订阅卡片显示主题、每日/每周计划、下次运行、最近结果和启停状态。
- 配置字段：名称、自然语言主题、RSS/Atom 或站点来源、包含关键词、排除关键词、频率、星期、执行时刻和 IANA 时区。
- 每日只要求时刻；每周还要求星期。首期不展示 Cron 文本框。
- 保存后创建或更新计划；“立即运行”创建独立运行，不改变下一次计划时间。
- 停用计划不删除定义、历史运行或既有简报。

## 简报与运行详情

- 资讯首页按日期显示已发布简报，点击进入标准文档编辑器。
- 运行详情显示配置快照、来源获取结果、去重、相关性筛选、摘要、聚合、质量检查和发布步骤。
- 每个来源显示标题、原链接、发布日期、抓取时间、是否采用和跳过原因。
- 失败步骤可重试；重试沿用运行幂等键并更新同一简报的新修订，不重复建文档。
- 单个来源失败不阻塞其他来源。缺少来源、引用或步骤失败时简报顶部显示结构化质量警告。

## 状态

| 状态         | 行为                                                     |
| ------------ | -------------------------------------------------------- |
| 无订阅       | 主操作“创建资讯订阅”，说明将自动沉淀到资讯知识库。       |
| 无新内容     | 仍创建简报，明确说明时间窗口内无符合条件内容。           |
| 部分完成     | 发布带警告的简报，并列出失败来源和可重试步骤。           |
| 全部获取失败 | 发布失败说明文档，不能生成未经来源支持的资讯结论。       |
| 运行中       | 展示当前步骤、已处理来源数和取消操作，不伪造完成百分比。 |
| 离线         | 已有简报可读；配置、立即运行和重试禁用。                 |

## 移动端、可访问性与动效

- 移动端可阅读订阅摘要、简报和运行状态，不可创建或修改订阅。
- 来源列表使用语义化列表；状态不只依赖颜色；外链标明将在新标签打开。
- 运行步骤用有限阶段过渡；完成时可显示一次 Toast，不进入全局通知中心。

## E2E 验收

1. 保存每日或每周订阅后显示正确时区和下次运行时间。
2. 手动与计划运行都只生成一个对应简报文档。
3. 部分来源失败仍发布文档，并显示与运行记录一致的质量警告。
4. 重试成功生成新修订，不复制简报或来源条目。
