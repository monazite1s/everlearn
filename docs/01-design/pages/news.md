# 页面规格：资讯

## 目的与路由

- `/news`：最近资讯条目流与简报回顾。条目是一等对象，简报是按日/周的聚合回顾，两者共享同一套条目数据。
- 页面 URL 保存 `tab=items|digests`、过滤条件 `topic`（订阅 ID）、`sourceType=rss|search`、`importance=high|normal|low`、条目详情 `?item=<uuid>` 与运行详情 `?run=<uuid>`；刷新和分享可恢复同一视图，过滤与 Tab 变化只使用 replace，打开详情使用 push。
- 订阅管理不占独立路由，收敛在页头「订阅」DropdownMenu 与编辑弹窗。
- 入口：一级导航、首页运行摘要、条目与运行深链。离开：简报文档（标准文档路由）、来源原文（新标签）、设置 Provider 或其他一级模块。

## 桌面布局

- 页头操作区只有「订阅」DropdownMenu：列出全部订阅（主题色点、主题名、启用状态、下次运行），菜单项为新建订阅、编辑、立即运行、启用/停用；页面无创作主操作。
- 主区顶部为 Tabs「条目流｜简报」，选中状态写入 `tab`。
- 条目流 tab 自上而下为过滤行与条目列表；条目详情在右侧 Sheet 展开，不离开列表。
- 简报 tab 为最近简报置顶摘要卡加按日列表。
- 过滤行：主题 Select（选项为订阅主题，点击即筛选）、来源类型 Select（全部/RSS/搜索）、重要性 Select（全部/高/普通/低）。任一过滤变化取消旧请求、清空游标并从第一页读取。

## 条目流

- 列表以安静的分隔行组织，不使用重卡片。每行结构固定：
  - 行首为主题色点（`chart-1..5` 固定映射，8px，仅装饰并对辅助技术隐藏）。
  - 第一行为重要性形状标记加标题；行尾为来源轮廓 Badge（来源图标与名称）和相对时间。
  - 第二行为摘要，最多两行截断，使用 `text-muted-foreground`。
- 标题是整行主链接；同一行不嵌套多个可聚焦目标，摘要与元信息不可点击。
- 排序固定为重要性降序后时间倒序：`high → normal → low` 各档内按发现时间倒序、ID 倒序，用户不可切换排序。
- 重要性只用形状语言：高=实心反转形状，中=同尺寸轮廓形状，低=默认不渲染形状；三档始终以文字提供「重要性：高/普通/低」，形状不单独承载语义。
- 彩色只允许主题色点，颜色来自订阅创建时分配的固定色槽；来源类型与重要性保持中性轮廓，不使用语义色。

## 条目详情 Sheet

- 桌面为 42rem 右侧 Sheet，≤768px 转为全屏；复用 shadcn Sheet 组件，不另写浮层。
- 内容顺序：标题、元信息行（主题色点与主题名、来源 Badge、发现时间、重要性文字）、LLM 处理后正文（纯文本分段渲染，不渲染外部 HTML，不归档外部全文）、操作行（「查看原文」外链，新标签打开并标注外域）。
- 次级入口：「处理过程」打开 `?run=<发现运行 ID>` 的运行详情（步骤、来源决策、相关性/重要性判定与跳过原因）；「查看主题条目」应用所属订阅的主题筛选。
- 打开时 push `?item=<uuid>`，关闭回退历史；深链直接访问时加载条目并展开 Sheet。
- 打开时焦点移入 Sheet，Tab 循环限制在 Sheet 内；关闭后焦点回到触发行。运行详情为居中 Dialog，`Escape` 逐层关闭（先 Dialog 后 Sheet）。

## 简报 tab

- 置顶摘要卡显示最近一份简报：标题、日期、聚合条目数、质量警告徽标和「打开简报」。
- 其下按日倒序列出历史简报：日期、标题、状态与警告；点击进入标准文档路由阅读和编辑，不在本页内嵌正文。
- 简报由条目聚合而成，不复制条目正文；无任何简报时显示结构化空态，不伪造占位简报。

## 订阅与运行

- 编辑弹窗字段：名称、自然语言主题、RSS/Atom 或站点来源（多条）、包含关键词、排除关键词、频率每日/每周、星期、执行时刻与 IANA 时区；不提供 Cron 文本框。
- 保存后创建或更新计划；「立即运行」创建独立运行，不改变下次计划时间；停用不删除历史运行与既有简报。
- 运行详情显示配置快照、时间窗口、状态、逐条来源决策和结构化质量警告；失败步骤以幂等键重试，重试成功更新同一简报的新修订，不重复建文档。
- LLM 相关性与重要性判定必须使用订阅自身主题，禁止跨订阅硬编码主题；搜索与 LLM Provider 均为 GLM，经服务端 Provider Adapter 调用，页面不感知 Provider 差异。

## 移动端

- 390px 下过滤行纵向堆叠，条目行保留双行结构，Tabs 保留。
- 条目详情为全屏 Sheet，顶部提供关闭；原文外链与处理过程保留。
- 订阅菜单与编辑弹窗不可用：移动端隐藏订阅创建、编辑、立即运行与启停，只保留阅读与状态查看。
- 运行详情为全屏 Dialog；简报 tab 完整可读并可跳转文档。

## 数据与接口

- 数据实体：`NewsSubscription`、`NewsSource`、`NewsItem`、`DigestRun`、`DigestItem`、`WorkflowRun`、输出 `Document`（系统资讯知识库）。
- 条目独立入库：采集成功的条目写入 `NewsItem`（标题、规范 URL、摘要、LLM 处理后正文、来源类型、订阅主题、重要性、内容指纹、发现时间），不依赖简报存在。
- `GET /api/v1/news-items`：参数 `subscriptionId/sourceType/importance/limit/cursor`，默认 20、最大 100；排序固定 `importance desc → discoveredAt desc → id desc`；响应 `{ items, nextCursor }`，条目投影含 `id/title/url/snippet/topic/colorSlot/sourceType/importance/discoveredAt/subscriptionId`；被判无关的条目不返回。
- `GET /api/v1/news-items/:id`：在流投影外返回 `processedContent`（LLM 处理后正文）、`relevance` 与 `discoveredRunId`；不存在或不属于当前用户统一 404。
- `GET /api/v1/news-digests`：简报按日列表 `{ items, nextCursor }`，项含 `id/title/digestDate/documentId/knowledgeBaseId/status/warningCount/itemCount`。
- `GET /api/v1/digest-runs/:id` 与步骤重试沿用既有契约；订阅管理沿用 `/news-subscriptions`。
- 游标为最大 512 字符 Base64URL，含排序键与过滤条件指纹；畸形、跨过滤条件或跨排序游标统一返回 `400 VALIDATION_FAILED`。

## 异步行为

- 立即运行与计划运行先建运行记录再入队；页面经运行详情轮询获取状态，不依赖推送。
- 条目在采集与判定完成后再进入条目流；相关性批量判定失败时全部按 `accepted + normal` 入库并记运行警告，不阻塞其他来源。
- 单来源失败不阻塞其他来源；部分成功以结构化警告呈现在简报顶部与运行详情。
- 页面停留期间运行完成只显示一次页面内 Toast，不进入全局通知中心。

## 状态与反馈

| 状态     | 行为                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 无订阅   | 结构化空态说明资讯能力，主行动「创建资讯订阅」打开编辑弹窗。                           |
| 首次加载 | 保留过滤行，列表区显示镜像行 Skeleton，不使用全屏 Spinner。                            |
| 零结果   | 保留筛选；有非默认筛选时唯一主行动为清除筛选，默认筛选时说明当前窗口暂无条目。         |
| 首屏失败 | 保留筛选，说明失败对象与原因类别，提供就地重试。                                       |
| 分页失败 | 保留已加载条目，列表末尾说明后续加载失败并提供重试。                                   |
| 详情失败 | Sheet 内说明失败并提供重试与关闭，不展示空壳详情。                                     |
| 部分成功 | 条目照常展示；简报与运行详情显示来源不足、失败步骤等结构化警告。                       |
| 运行中   | 运行详情显示当前步骤与已处理来源数，不伪造百分比。                                     |
| 离线     | 已加载条目与简报可读；过滤请求、加载更多、订阅编辑与立即运行禁用。                     |
| 无权限   | 条目、订阅或运行不存在或不属于当前用户时统一不可访问状态，不泄露标题，404 不提供重试。 |
| 请求竞态 | 过滤变化取消旧请求；迟到响应不得覆盖当前过滤。                                         |

## 可访问性与动效

- 标签双通道：重要性形状与文字、主题色点与主题名、来源图标与来源名总是同时在场；低重要性不渲染形状但文字可感知。
- 键盘流与搜索页同一约定：`j`/`k` 在条目行间移动（roving tabindex，当前行 `aria-current="true"` 并滚动跟随），`Enter` 打开详情，`Escape` 逐层关闭；焦点在输入框内或 IME composing 时不拦截按键，`Escape` 只在未被浮层消费且未 `defaultPrevented` 时生效。
- Tabs 支持方向键；Sheet 焦点圈闭与焦点归还符合浮层规范；条目总数在一次响应完成后经 `aria-live` 宣告一次。
- 动效仅用短过渡：行 hover 120–180ms 颜色与边界，Sheet 220–320ms 滑入；reduced motion 下取消位移，仅保留即时显隐或透明度。

## E2E 验收

1. RSS 与搜索来源采集后条目独立出现在条目流，无需等待简报；排序符合重要性优先、同档时间倒序。
2. 主题、来源类型、重要性筛选正确过滤、写入 URL 并在刷新后恢复；`?item=` 深链直接展开正确条目。
3. 相关性判定使用订阅自身主题：mock LLM 断言判定请求包含订阅主题，不同订阅互不串扰。
4. Sheet 内查看原文在新标签打开原始 URL；「处理过程」展示与运行记录一致的来源决策与跳过原因。
5. 简报 tab 置顶卡与按日列表与已发布简报一致，点击进入文档路由；简报不复制条目正文。
6. 状态表全部行为通过：无订阅、加载、零结果、首屏失败、分页失败、详情失败、部分成功、离线、无权限与请求竞态。
7. `j/k`、`Enter`、`Escape` 全键盘可完成浏览与关闭；axe Critical/Serious 零问题；浅色、深色、390px 与 reduced motion 走查通过。
