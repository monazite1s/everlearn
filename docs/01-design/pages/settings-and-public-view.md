# 页面规格：设置与公共阅读

## 设置页

### 路由与分区

- `/settings/appearance`：主题预设、浅色/深色/跟随系统。
- `/settings/providers`：LLM 与 Search Provider 配置和连接测试。
- `/settings/system`：时区、对象存储、数据库/Redis 状态和版本信息。
- 首期 `/settings` 重定向到外观设置；账号与分享配置在 M7 增加。
- 入口：一级导航和 Provider 缺失提示。离开：原功能返回链接或其他一级模块。

### 数据与接口

- 数据：`UserPreference`、脱敏 `ProviderConfiguration`、`SystemHealth`。
- 外观与时区使用设置 API；Provider 使用只写密钥、脱敏读取和连接测试端点；诊断为只读聚合。
- 设置不创建文档修订；时区与 Provider 修改记录审计事件，但不保存密钥原值。

### 行为

- Provider 密钥写入后只显示是否已配置和末尾掩码，不提供读取原值接口。
- 连接测试只返回成功、错误类别和可行动提示，不回显请求头或响应正文。
- 用户时区使用 IANA 标识，修改后只影响未来调度，不修改历史运行快照。
- 主题切换即时预览并持久化；组件只读取语义 Token，不按主题写业务分支。
- 系统诊断只读展示依赖健康状态，不允许从 UI 执行数据库修复或清空队列。

### 状态与验收

- Provider 未配置时相关功能明确指向设置页，知识库核心仍可用。
- 保存失败保留当前输入；离开含未保存密钥的页面前需要确认。
- 移动端可切换主题和查看诊断，不可编辑 Provider 密钥。
- E2E：主题刷新后保持；密钥不可从响应重新读取；时区变更不改变既有运行显示。

## 公共阅读与克隆（M7）

### 路由与布局

- `/share/:shareToken` 展示知识库或文档子树的只读公开内容。
- 页面不加载私有导航、编辑器工具栏、修订、AI 对话或运行记录。
- 内容最大宽度 760px；知识库分享提供限定在共享子树内的目录导航。
- 顶部显示标题、所有者展示名、发布时间、更新时间和“克隆到我的知识库”。
- 入口：共享链接。离开：外部来源、登录或克隆后的私有副本。

### 数据与接口

- 数据：公开 `ShareSnapshot`、共享目录、附件投影和 `CloneRecord`。
- 公共 API 只接受分享 Token；克隆 API 需要登录会话和幂等键；两者均不返回私有实体。
- 公开快照不随私有修订变化；重新发布产生新快照，克隆产生目标用户的新文档修订。

### 分享行为

- 分享默认 `noindex`，Token 不可枚举，可设置过期时间并可立即撤销。
- 分享读取已发布内容快照；私有后续编辑不会静默改变外部内容，重新发布才更新快照。
- 附件仅允许访问共享快照实际引用且已复制授权的对象。
- 未登录访客只读；登录用户可克隆整个知识库或当前文档子树。

### 克隆行为

- 克隆深拷贝文档树、正文、标签和可访问附件，生成新 ID 与稳定 Block ID 映射。
- 新副本保存原分享、原对象和克隆时间作为来源，不建立同步或合并关系。
- 重复提交使用幂等键，同一请求只创建一个副本；目标归用户所有并可独立修改。

### 状态与验收

- 不存在、未发布、已撤销和已过期统一返回不可访问页面，不泄露对象是否存在。
- 分享正文经过安全渲染和协议白名单；公开接口限流。
- E2E：撤销立即失效；私有数据不可访问；克隆保持树结构且双方修改互不影响。
