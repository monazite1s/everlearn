# 页面规格：文档编辑器

## 目的与路由

- 路由：`/knowledge/:knowledgeBaseId/documents/:documentId`。
- 目的：完成结构化写作、修订恢复、知识连接和有引用的 AI 辅助。
- 入口：文档树、首页最近文档、搜索结果、反向链接、资讯或教程产物。

## 数据与接口

- 数据：`Document`、`DocumentRevision`、`Attachment`、`DocumentLink`、`Generation`、`GenerationCitation`。
- 使用文档保存/移动、修订、附件、链接、Generation、问答和 SSE 接口；所有写入提交文档版本。
- 手工、AI 接受、导入和恢复修订必须区分来源并关联对应运行；读取旧修订不得改变当前文档。
- 首期固定本地用户可编辑；M7 的公开访问使用独立只读渲染器，不复用私有编辑 API。

## 桌面布局

- 左栏是当前知识库文档树；中央为面包屑、标题、保存状态和正文；右栏在“AI、引用、修订、属性”之间切换。
- 正文最大宽度 760px。宽表格允许局部横向滚动，不扩大整页。
- 右栏可折叠；AI 生成不得覆盖正文或阻止手工编辑其他块。

## 编辑能力

- Block：段落、四级标题、无序/有序/任务列表、引用、Callout、代码块、表格、图片、附件、链接和分隔线。
- Schema v1 当前闭集：段落、四级标题、无序/有序列表、引用、代码块、图片、附件、链接和分隔线；任务列表、Callout 与表格属后续 Schema 扩容任务（表格局部横向滚动随其接入，代码块局部滚动已生效）。
- 支持 Markdown 快捷输入与 Slash Menu；块重排首期经剪切/粘贴完成，拖拽重排与拖拽手柄属后续编辑体验任务。
- 每个可引用 Block 保存稳定 `blockId`；复制、拆分和合并时按编辑器规则生成或保留 ID，禁止出现重复 ID。
- 内部链接通过标题搜索插入，保存后更新反向链接；目标删除时保留失效链接提示。
- 附件只展示或下载，不解析进 AI 上下文；上传失败保留可重试占位，不写入无效 Block。上传上限：图片 ≤10MB（png/jpeg/webp/gif，首期拒绝 svg）；通用附件 ≤25MB（扩展名白名单）。未引用的上传对象保留 24 小时后由孤儿清理删除。

## 保存与修订

- 内容变化后防抖自动保存；标题和正文使用同一个乐观版本号提交。
- 保存冲突停止覆盖并提示重新加载或复制本地内容；首期不做自动合并。
- 智能修订在离开文档、持续编辑间隔、AI 接受、导入和恢复时创建，不为每次防抖保存创建快照。
- 恢复修订先预览，再创建新的恢复修订；历史修订不可改写。

## AI 交互

- 选区菜单提供改写、扩写、压缩、解释和自定义指令；结果进入差异预览。
- AI 侧栏支持当前文档或当前知识库问答，范围切换必须清晰可见。
- 每条答案引用文档标题和 `blockId`；点击引用定位并短暂强调对应 Block。
- 对已有正文的生成只有“接受”后写入并创建 `ai` 修订；拒绝、取消和失败不改变正文。
- 新建文档型生成允许后台自动写入，但仍保留生成记录和修订。

## 状态

| 状态       | 行为                                             |
| ---------- | ------------------------------------------------ |
| 正在保存   | 标题旁显示非阻塞状态。                           |
| 保存失败   | 保留本地内容，提供重试和复制内容，不自动离页。   |
| 版本冲突   | 禁止继续覆盖；展示服务端版本更新时间。           |
| AI 运行    | 可取消；用户仍可编辑非目标块。                   |
| 引用不足   | 明确显示“知识库中未找到足够依据”，不生成伪引用。 |
| 文档已删除 | 显示删除提示并提供回收站入口。                   |
| 离线       | 已加载正文只读；不承诺离线编辑或同步。           |

## 移动端、可访问性与动效

- 移动端以只读渲染器显示正文、目录、内部链接和引用；不加载 Tiptap 编辑实例。
- 工具栏与 Slash Menu 可完全键盘操作；拖拽手柄与差异视图的键盘操作随其接入实现；代码块和表格有可读标签。
- 流式文本不逐字符触发屏幕阅读器；以阶段状态和完成通知报告。
- 引用定位使用一次 320ms 背景强调；reduced motion 下立即显示静态强调。

## E2E 验收

1. 编辑后自动保存，刷新可恢复正文、标题、结构和 Block ID。
2. 修订预览和恢复不会删除历史；恢复产生新修订。
3. AI 接受写入目标范围，拒绝或取消保持原文不变。
4. 问答引用可定位到正确 Block；无依据时不返回伪造引用。
5. 内部链接创建后在目标文档显示反向链接。
