# 页面规格：知识库

## 目的与路由

- `/knowledge`：知识库列表、Inbox、回收站和全局搜索入口。
- `/knowledge/:knowledgeBaseId`：知识库概览与文档树。
- `/knowledge/inbox`：未归档快速记录。
- `/knowledge/trash`：已删除知识库和文档。
- 进入文档后使用 `/knowledge/:knowledgeBaseId/documents/:documentId`。
- 入口：一级导航、首页知识库、全局搜索和最近文档。离开：文档编辑器、首页或其他一级模块。

## 数据与接口

- 数据：`KnowledgeBase`、`DocumentTreeItem`、`InboxItem`、`TrashItem`。
- 使用知识库、文档树、Inbox 和回收站 API；移动与恢复提交对象 `version` 和幂等键。
- 树操作本身不创建正文修订；恢复文档内容时创建 `restore` 修订。
- 首期固定本地用户拥有全部对象；M7 后所有请求按当前会话验证 `ownerId`。

## 知识库列表

- 主区按最近活动显示名称、描述、文档数和更新时间；首期不显示知识库分组。
- 支持创建、重命名、归档和移入回收站。删除必须明确说明包含的文档子树。
- 系统“资讯知识库”带系统标识，允许阅读、编辑和删除其中简报，但不可把其他知识库标记为系统库。
- Inbox 和回收站是固定次级入口，不伪装成普通知识库。

## 知识库概览

- 左栏显示可展开的文档树；每个节点都是文档，可同时包含正文和子文档。
- 中央显示知识库说明、最近文档、根文档和新建文档操作。
- 新建子文档默认位于当前选中节点下；未选中时创建根文档。
- 拖拽移动显示目标父级和顺序，拒绝移动到自身或后代。
- 文档数量很大时按展开节点延迟加载，不一次返回完整树。

## Inbox

- 每条记录保存原始文本或 URL、创建时间和处理状态。
- 用户可打开为临时文档、移动到任一知识库父节点或删除。
- 移动成功后成为普通文档并离开 Inbox；失败不得删除原记录。
- Inbox 不用于资讯审核、系统通知或 AI 运行结果。

## 回收站

- 显示对象类型、原知识库、原路径、删除时间和永久删除时间。
- 恢复文档包含完整子树；父节点不存在时恢复到原知识库根部。
- 原知识库不存在时必须先恢复知识库，不能把文档静默移入其他知识库。
- 永久删除需要二次确认；到期清理由 Worker 执行并记录数量和错误。

## 状态与反馈

| 状态 | 行为 |
|---|---|
| 空知识库 | 显示新建首篇文档，不生成示例内容。 |
| 树加载失败 | 保留当前正文，树区域提供重试。 |
| 移动冲突 | 回滚视觉位置并说明非法父子关系或版本冲突。 |
| 删除中 | 禁止重复提交；成功后从正常列表移除。 |
| 离线 | 允许查看已加载文档；禁用树修改。 |
| 无权限 | 返回统一不可访问状态，不显示对象标题。 |

## 移动端

移动端支持知识库与文档树阅读、搜索和打开文档；隐藏创建、重命名、拖拽、删除、恢复和 Inbox 处理操作。

## E2E 验收

1. 可创建多个知识库，知识库之间不能形成父子关系。
2. 文档可无限嵌套；非法子树移动被拒绝且 UI 恢复原位。
3. Inbox 记录移动成功后只生成一个目标文档。
4. 删除和恢复保持完整子树；30 天期限与永久删除提示一致。
